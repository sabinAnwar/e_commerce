# E-Commerce

A modern e-commerce application with React and Vite.

## Features

- React-based user interface
- Fast development with Vite and Hot Module Replacement (HMR)
- ESLint support
- Tailwind CSS styling
- Fast Refresh using Babel or SWC

## Technologies

- React
- Vite
- Tailwind CSS
- ESLint

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Install Tailwind CSS

```bash
npm install tailwindcss @tailwindcss/vite
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at the local URL shown in your terminal.

## Available Fast Refresh Plugins

This project can use either of the following React plugins:

- `@vitejs/plugin-react` — uses Babel for Fast Refresh
- `@vitejs/plugin-react-swc` — uses SWC for Fast Refresh

## Build for Production

```bash
npm run build
```

## Preview the Production Build

```bash
npm run preview
```

## Lint the Project

```bash
npm run lint
```
